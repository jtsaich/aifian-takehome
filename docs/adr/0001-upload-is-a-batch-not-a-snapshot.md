# 上傳是一批訂單明細，不是門市的快照

門市每天傳的檔案，內容可能是當天接到的單，也可能是一直往下加的整份檔案；單裡的取貨日則可能落在下週、下個月，或更晚。如果把每次上傳當成門市全部訂單的快照，「這次檔案裡沒有出現的單」就會被誤判成取消。所以我們把每次上傳當成一批訂單明細：檔案裡沒出現的單一律不處理；同一個單號再次出現、而且內容不同，才算修改。取消要由門市明確寫出來。

## Considered Options

- 整份快照，再跟前一版比對差異：門市只要換一份新檔、或刪掉舊的列，系統就會大量誤判成取消，所以不採用。
- 以取貨月份切快照：前提是門市每月開一份新檔，但現場不是這樣記的，所以不採用。
