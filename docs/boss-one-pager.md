# 喜餅訂單：第一階段說明

喜餅占營收約四成。上一季有 3 筆喜餅訂單的日期或數量記錯，每一筆都退了款、留下負評；中央廚房也要等各店傳 Excel，才知道下週做多少。第一階段先處理這兩件事。

做法盡量不動到門市：店員照舊接電話、記 Excel、傳到現在的 LINE 群組，只換一份六家共用的訂單表格，再把中央廚房的 LINE 官方帳號加進群組。門市一傳檔，官方帳號就在群組裡回覆收到幾張單、第幾列寫錯、哪幾筆改單要總部點頭。門市不用裝新軟體，也不用買新設備。

## 第一週您會拿到什麼

- 第 1–2 天：跟您、廚房和試用門市店長各談半小時，把上一季那 3 筆逐筆對回去，看錯在哪一步，整理成一頁給您。
- 第 2–3 天：訂單表格定稿，盡量照門市現在的欄位；每家門市一本預先編號的訂購單。
- 第 4–5 天：一家門市開始試用，舊做法照常進行，兩邊每天對一次。
- 一個網頁：廚房看每天要交哪一款、幾盒；總部看待確認的改單；您看回頭客。都能下載成 Excel。
- 週末一頁小結：攔下幾筆錯，廚房的數字跟舊做法有沒有差。

## 需要您和 POS 廠商配合什麼

- 您：指定一位總部負責人處理改單，選一家願意先試的門市；提供喜餅品項清單和各店新舊 Excel；決定取貨前幾天起改單要經總部同意（建議 7 天，試用時再調）。
- POS 廠商：第一階段不必動手。我們想先問兩件調整設定的事：每晚的報表能不能自動放到固定資料夾；收銀時能不能另開「喜餅訂單取貨」品項，跟現場購買分開。這是第二階段把訂單和銷售對起來的前提。

## 用什麼判斷有沒有成功

看一個數字：**在客人取貨前被攔下、而且改好的錯誤單數**。日期寫錯、數量不對、過了截止日才改單，每攔下並改好一筆就算一筆。退款和負評就是從這些錯來的，每週都數得出來。上一季的 3 筆是最後要壓到 0 的結果，但一季只有 3 筆，幾週內看不出差別，放在季末驗收。

## 看到什麼結果就停下來

- 追那 3 筆時發現錯在電話裡就發生了（客人說 15 號、店員寫成 16 號）。表格擋不住這種錯，我們會先停下系統，改從接電話下手，例如掛電話前覆誦、用 LINE 傳確認給客人。
- 試用兩週，門市按時傳檔不到八成，或店員說接單變慢、調整後還是一樣：給門市的負擔太重，停下來重談。
- 兩週內廚房沒打開過數量頁面，還在等 Excel：做出來的不是廚房要的，停下來問廚房。

## 關於會員 App

這一階段累積的客人電話和訂單紀錄，就是之後做會員的底。第一次見面我們想先聽您希望會員帶來什麼；很多店家用 LINE 官方帳號的會員卡就夠了，成本通常比開發 App 低。客人留電話是為了訂喜餅，要拿來發優惠得先請客人同意加入，這一步會一起設計。
