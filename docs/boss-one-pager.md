# 喜餅訂單：第一階段說明

【Jack 補：開頭一兩句，用老闆熟悉的話講這件事為什麼先做（例如上一季那 3 筆退款）】

門市照舊用電話接單、記 Excel，檔案也照舊傳到現在那個 LINE 群組。我們只換一份統一的訂單表格，並把中央廚房的 LINE 官方帳號加進群組。每次門市傳檔，官方帳號會在群組裡馬上回覆：收到幾張單、哪一列漏填或寫錯、哪些改單需要總部點頭。

## 第一週您會拿到什麼

- 一份六家門市共用的喜餅訂單表格，以及每家門市一本預先編好號碼的訂購單（門市原本有編號的就沿用）。
- 中央廚房的官方帳號加進群組，先選一家門市試用。試用期間舊的做法照常進行，兩邊對得上才換。
- 一個網頁，廚房打開就看得到「哪一天要交哪一款、幾盒」，總部看得到需要確認的改單。都能下載成 Excel。

## 需要您和 POS 廠商配合什麼

- 您：指定一位總部的負責人，處理門市傳上來的改單；選定第一家試用門市；提供目前的喜餅品項清單和各店現有的 Excel 檔。
- 您：決定取貨前幾天之後，改數量、改日期要先經過總部同意（我們建議 7 天，可以再調）。
- POS 廠商：每晚的銷售報表放到固定的共用資料夾；在收銀品項裡另外開一個「喜餅訂單取貨」，跟門市現場買的分開。這兩件都是調整設定，不必改功能，第一階段也不會用到 POS 的資料，是替下一步預先準備。

## 用什麼判斷有沒有成功

主要看「在客人取貨前就被抓出來並改正的錯誤有幾筆」。上一季出事的 3 筆太少，幾週內看不出差別，所以當作輔助參考。另外也看兩件事：廚房每週拿到下週數量的時間有沒有提早，門市有沒有每天按時傳檔。

【Jack 補：試行前和老闆一起訂下目標數字，例如廚房要在週幾之前拿到數量】

## 看到什麼結果就停下來

試行兩週後，只要出現下面任何一種情況，我們就先停下來，回頭跟您和門市重新談流程：

- 門市按時傳檔的比例低於八成。
- 試用門市反映新表格讓接單變慢，調整之後還是一樣。
- 廚房完全沒有打開過數量頁面。
