# 04: 欄位檢查、欄名放寬與多分頁

**What to build:** 門市傳來的檔案就算有錯、格式有點走樣，系統還是要逐列告訴她哪裡要改，沒問題的列照收。店員要能看懂回覆，不用打電話問總部。

**Blocked by:** 02（骨架：模擬群組上傳 → 總表）

**Status:** ready-for-agent

- [ ] 錯誤（這一列不收）：
  - 缺單號
  - 日期解析不出來
  - 盒數不是正整數
  - 品項既不在商品清單裡，也不是品項別名
- [ ] 同一個單號的各列，訂單層欄位不一致時，整張喜餅訂單都不收。
- [ ] 警告（照收，但會標出來）：
  - 取貨日已經過了
  - 取貨日離今天太近
  - 盒數超過門檻
  - 電話格式異常
  - 同一支電話、同一個取貨日重複下單
- [ ] 日期要能讀這幾種寫法：民國年、西元年、`10/25`，以及 Excel 的日期格式。
- [ ] 欄位順序不同、欄名用同義的寫法、多了店員自己加的欄位，都照常處理。
- [ ] 分頁的處理：
  - 欄名比對得上範本的分頁都要讀。
  - 比對不上、被略過的分頁，要列在回覆裡。
  - 同一個單號在兩個分頁裡內容不一致時，整張單不收。
- [ ] 回覆的格式：
  - 每個問題都寫出位置（分頁名加 Excel 列號），再用門市人員看得懂的話說明原因。
  - 錯誤和警告分開列。
- [ ] 品項只認清單上的名稱和品項別名，不做模糊比對。
- [ ] 自動化測試：01 的每一份模擬檔，系統實際的回覆都要跟對照表一致。
