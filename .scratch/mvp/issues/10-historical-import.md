# 10: 歷史資料匯入

**What to build:** 門市上線前的舊 Excel，由 FDE 轉成範本格式，再由總部從網頁匯入。匯入的資料會長進客人資料，但不會影響目前的生產流程。

**Blocked by:** 01（範本與模擬資料）、09（客人資料）

**Status:** ready-for-agent

- [ ] 01 的兩份舊格式檔，各用一支轉換工具轉成範本格式。轉換工具是 FDE 的導入工具，不是產品功能。
- [ ] 舊單沒有單號時，由轉換工具補一個單號，而且一看就知道是歷史資料。
- [ ] 從網頁匯入的資料標記為歷史資料：不套用修改截止點，不產生待確認，也不發 LINE 回覆。
- [ ] 匯入後，客人資料裡看得到這些歷史訂單；取貨日已經過去的單，不會出現在廚房彙總裡。
- [ ] 同一份檔案重複匯入，不會多出重複的訂單。
