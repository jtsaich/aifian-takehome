# 09: 客人資料

**What to build:** 老闆和總部可以看到每位客人的訂單歷史，知道誰是回頭客。這裡說的「客人」，指的是一支正規化之後的電話號碼。客人資料只給內部查詢，不是會員。

**Blocked by:** 04（欄位檢查、欄名放寬與多分頁）、05（角色登入）

**Status:** ready-for-agent

- [ ] 電話正規化：手機、含區碼的市話、+886 開頭、中間有空白或 dash，只要是同一支電話，都要對到同一位客人。無法正規化的列給警告。
- [ ] 客人頁顯示：
  - 訂單數、總盒數
  - 第一次和最近一次的接單日
  - 下過單的門市
  - 訂購人姓名；同一支電話有不同姓名時要標出來
- [ ] 從客人頁可以點到這位客人的每一張喜餅訂單。
- [ ] 只有老闆和總部看得到，廚房看不到。
- [ ] 客人資料可以下載 .xlsx。
- [ ] 頁面上沒有任何發訊息的功能。
- [ ] 自動化測試：電話正規化規則，各種寫法都要測到。
