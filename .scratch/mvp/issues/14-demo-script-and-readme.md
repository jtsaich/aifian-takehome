**Status:** resolved

- [x] 劇本依序是：
  1. 門市傳了一份有錯的檔案，回覆逐列指出問題。
  2. 門市修正後重傳，廚房彙總跟著更新。
  3. 門市追加盒數。
  4. 一筆過了修改截止點的修改，變成待確認。
  5. 總部退回這筆修改。
  6. 門市又傳了同樣的內容，收到「已被總部退回」的提醒。
  7. 門市把 Excel 改回原本的數字，提醒消失。
  8. 客人頁看得到回頭客。
  9. 匯入歷史資料。
- [x] 每一步都印出 LINE 回覆的文字，以及該看的畫面網址。
