# 12: LINE OA 接入與門市綁定

**What to build:** 門市在群組裡傳範本檔，1 分鐘內就在群組裡收到回覆，內容跟模擬上傳頁顯示的一模一樣。第一次傳檔的人會被記下來，由總部確認他屬於哪家門市。

**Blocked by:** 03（部署到 Cloud Run＋Neon）、04（欄位檢查、欄名放寬與多分頁）、05（角色登入）、11（[HITL] 建 LINE OA 與 demo 群組）

**Status:** resolved

- [x] 驗證 webhook 簽章，簽章不對的請求直接拒絕。
- [x] 依 `webhookEventId` 去重複，LINE 重送的事件不會被處理兩次。
- [x] 一收到 file 事件就立刻下載並保存原檔，因為 LINE 只保存檔案內容一段時間。
- [x] 只處理有範本門市代碼和版本儲存格的檔案。其他檔案一律不回應，這樣群組裡的人傳別的檔案，bot 也不會插話。
- [x] 一律用 reply 回覆，不用 push。回覆內容跟模擬上傳頁的一致。
- [x] 回覆必須在處理完之後送出。Cloud Run 在送出 HTTP 回應之後會限制 CPU，所以處理和回覆都要在回應前完成。
- [x] 傳檔者與門市綁定：
  - 新的傳檔者：回覆第一行寫「已記錄您為 ○○門市（待總部確認）」，檔案照常處理。
  - 總部在網頁上確認門市綁定。
  - 已綁定的傳檔者傳了別家門市的檔案：照常處理，但給警告。
  - 一家門市可以有好幾位傳檔者。
- [x] 處理失敗也要回覆，寫「這份檔案沒處理成功，總部已收到通知」，同時保存原檔和失敗原因。
- [x] log 裡不能出現姓名和電話。
- [x] 在 11 建好的群組裡，實際傳一份 01 的檔案，確認一切正常。
