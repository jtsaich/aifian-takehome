# 05: 角色登入

**What to build:** 總部人員、廚房、老闆各自登入，各自只看得到自己該看的頁面。門市沒有帳號，也不需要登入。

**Blocked by:** 02（骨架：模擬群組上傳 → 總表）

**Status:** ready-for-agent

- [ ] 總部人員每人一個帳號。
- [ ] 廚房共用一個帳號，只能看總表和廚房彙總。
- [ ] 老闆的帳號可以看全部頁面。
- [ ] 沒有登入的人看不到任何訂單或客人資料。
- [ ] 每一個寫入動作都要記錄是哪個帳號做的。
- [ ] demo 帳號預先建好，帳密寫在 README。
- [ ] 密碼不能用明碼儲存。
- [ ] 自動化測試：每個角色去開不該看的頁面，都會被擋下。
